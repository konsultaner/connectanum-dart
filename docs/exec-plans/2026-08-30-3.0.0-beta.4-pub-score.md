# 3.0.0-beta.4 Pub Score Readiness

Status: active
Started: 2026-08-30

## Goal

Publish a synchronized `3.0.0-beta.4` Dart package and native crate graph whose
seven pub.dev packages qualify for the full 160-point package score while
preserving the existing runtime and hosted-package behavior.

## Release Contract

- All seven Dart packages and three Rust crates share `3.0.0-beta.4`.
- Every package archive includes a Dart example, package-local analysis
  settings, README, changelog, license, and score-ready package metadata.
- Public API documentation coverage remains above pub.dev's 20 percent scoring
  threshold for every package.
- Client and router use stable `hooks` and `code_assets` APIs and derive the
  matching beta.4 native release tag in isolated hosted installs.
- Package publication follows the dependency order: core, client, MCP, router,
  compatibility facade, auth server, then benchmarks.
- The standalone consumer example remains on the last complete published graph
  until beta.4 packages and native assets are available.

## Work

1. Add missing package examples, metadata, API documentation, and package-local
   analysis settings.
2. Adopt stable native-hook dependencies and raise the supported Dart floor to
   3.10.
3. Advance every package, crate, runtime identity, changelog, and release test
   to beta.4.
4. Run score evidence, package dry-runs, focused hook tests, `bin/test-fast`,
   and `bin/verify`.
5. Promote the verified commit, publish native assets and packages, confirm the
   hosted scores, and repin the standalone consumer example.
