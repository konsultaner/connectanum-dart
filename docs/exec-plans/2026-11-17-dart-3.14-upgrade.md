Status: active; recurrent cold-cycle RSS and project coverage failures block
acceptance; current macOS validation is unavailable due runner capacity.

## Scope

Pin the standalone Dart SDK to 3.14.0 in `.tool-versions`, all direct GitHub
Actions setup steps and all eight reusable package publishing jobs. Keep the
shared pub-cache keys aligned and update the existing CI SDK expectation.
Package SDK lower bounds stay at 3.10.0. Existing release, coverage, mutation
and performance gates remain in force.

The isolated branch carries the SDK changes from `77b1c4ca` onto current
`master`, plus the newer ObjectBox and Intel diagnostic workflow pins. It
does not import the mutation-runner branch's 23 older commits. Current release
and execution-plan history is preserved.
