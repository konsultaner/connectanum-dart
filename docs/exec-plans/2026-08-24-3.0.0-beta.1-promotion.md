# 3.0.0-beta.1 Promotion

Status: active
Started: 2026-08-24

## Goal

Promote the completed router-hosted MCP, asynchronous SCRAM, and multi-gigabit
transport work to the audited GitHub `master` branch as one synchronized
`3.0.0-beta.1` release candidate for consumer application testing.

## Release Contract

- All seven Dart packages and three Rust crates share `3.0.0-beta.1`.
- Public workspace dependencies use `^3.0.0-beta.1`.
- Runtime MCP identities, changelogs, installation guidance, and release gates
  expose the same beta version.
- Full local verification and strict package dry-runs pass before promotion.
- GitHub `master` is the audited release branch. GitLab `master` moves only by
  fast-forward.
- Package publish tags remain operator-gated and are not implied by pushing
  `master`.

## Work

1. Synchronize package, crate, dependency, runtime, changelog, and release-tool
   version surfaces at `3.0.0-beta.1`.
2. Run focused release validation, strict package dry-runs, and `bin/verify`.
3. Commit the completed implementation and release metadata, then push the
   feature branch.
4. Fast-forward eligible `master` refs and push GitHub `master`.
5. Watch exact-head deployment workflows and run the strict deployment audit.

## Progress

- 2026-08-24: User approved promotion to `master` for downstream beta testing.
- 2026-08-24: Pre-promotion `bin/verify` passed on the complete implementation
  worktree, including Rust, Dart, package, consumer, live WAMP/MCP/auth, remote
  auth, and Chrome Dart2Wasm coverage.
