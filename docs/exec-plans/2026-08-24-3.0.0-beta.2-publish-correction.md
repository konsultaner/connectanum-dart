# 3.0.0-beta.2 Publish Correction

Status: active
Started: 2026-08-24

## Goal

Publish a synchronized `3.0.0-beta.2` package, native artifact, and router image
release that installs and executes from pub.dev without requiring the private
monorepo layout or manual native release-tag configuration.

## Release Contract

- All seven Dart packages and three Rust crates share `3.0.0-beta.2`.
- Public workspace dependencies use `^3.0.0-beta.2`.
- Source checkouts build the checked-out Rust workspace unless explicitly
  configured otherwise.
- Isolated hosted packages derive `v<package-version>`, verify the matching
  published checksum, and bundle the supported host library.
- Explicit native-library, release-repository, release-tag, and skip-build
  settings retain precedence.
- A fresh pub cache resolves all seven packages and executes the packaged router
  help path before the correction is considered complete.
