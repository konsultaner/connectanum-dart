# 3.0.0-beta.5 Repair Release

Status: active
Started: 2026-08-30

## Goal

Publish one synchronized `3.0.0-beta.5` Dart and native graph that fixes
repeated native-hook installation on macOS, gives all seven packages the
canonical pub.dev example entrypoint, and makes the current benchmark evidence
visible on the `connectanum_bench` package page.

## Release Contract

- All seven Dart packages and three Rust crates share `3.0.0-beta.5`.
- Client and router publish every configured, built, or downloaded native
  library through staged atomic replacement.
- Every Dart archive contains `example/main.dart`; the benchmark archive also
  contains the current 78-workload transport matrix with Gbit/s units,
  methodology, hosted evidence, and reproduction links.
- The WampApp benchmark runs real loopback networking without installing
  Flutter's mocked HTTP test binding and passes the complete production gate.
- Native artifacts are published before package tags, and package publication
  follows core, client, MCP, router, compatibility facade, auth server, then
  benchmarks.
- The standalone consumer remains pinned to exact hosted beta.4 packages until
  beta.5 is indexed, then advances as a separate hosted-graph verification.

## Work

1. Advance package, crate, runtime identity, test, and changelog surfaces to
   beta.5 while retaining the beta.4 external-consumer lockfiles.
2. Validate hook regressions, package score assets, benchmark README content,
   WampApp production gates, strict package archives, and `bin/verify`.
3. Promote through protected `master` with a green GitHub deployment chain.
4. Publish matching native assets, then publish all seven package tags in
   dependency order and confirm publisher, version, score, and README evidence.
5. Repin the standalone consumer to exact hosted beta.5 packages and repeat its
   complete smoke gate.
